OwlThread

Ambient Memory for Builders

Save useful project context, organize durable facts, and get a cited brief for your next task. Version 1.5.0 is a local release candidate.

Get Started Documentation

How It Works

🔍

1. Capture

Choose browser notes, CLI captures or opt-in clipboard and experimental IDE sources.

🧠

2. Extract

Extracts supported facts with local rules or a provider you configure, preserving source and history.

⚡

3. Prime

Delivers context-ready briefs on demand exactly when you need them.

Features

MIT-licensed source

OwlThread has no subscription. Optional remote model providers may charge for requests.

Fully Customizable Prompts

Tailor the extraction and priming logic directly from the UI to match your stack.

Local fallback available

Use local rules without a provider key, or configure your own local Ollama installation.

Browser Extension

Save selected passages with a small companion. Page understanding runs only when requested.

4-Quadrant Memory

Organizes architecture, business rules, settled decisions and open questions.

Explicit privacy choices

Memory is stored in local SQLite. A remote model receives the context needed for your requested features.

Experimental IDE connectors

Opt-in Cursor and VS Code chat-store readers have fixture coverage. Changing live formats may need manual capture.

Query & Primer Engine

State your task and copy a project-scoped brief with memory references into your editor or chat.

# Start the background daemon
