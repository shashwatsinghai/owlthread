OWLTHREAD · BROWSER COMPANION

One home for your useful thoughts.

Your desktop app holds the model settings, API key and shared memory. The extension brings a small companion to your browser and syncs the notes you choose.

Connect once, use across browsers

  1. Start Launch_OwlThread.bat (source), or Open OwlThread.bat in the Windows release.
  2. In OwlThread desktop Settings, optionally select a model provider for extraction and synthesis. Raw browser capture itself does not require a model.
  3. Load the extension folder in Chrome or Brave through Developer mode → Load unpacked. Repeat in each browser on this computer.
  4. In desktop Settings choose Copy pairing secret. Paste it only into the popup's Preferences & connection → Connection settings, then pair. Choose the capture project there. Never paste this secret into a website. Revoke browser connections in desktop Settings to rotate it for every browser.

All browsers on this computer connect to the same local service at 127.0.0.1:41789. This does not sync between separate computers. Each browser remembers its own site choices and pending captures.

A small owl that respects your choices

The cozy developer owl is 64 pixels wide, with code-bracket ears and a soft green hoodie. Its eyes follow your cursor and blink naturally. It opens a notebook and writes while saving, holds a magnifying glass while understanding a page, and gives a small happy hop after success. It grows sleepy after a quiet spell and wakes when you return. Movement follows your motion preference, including reduced motion. Click to open, drag to move, or use arrow keys while it is focused. Escape closes the panel. It disappears during fullscreen playback.

Never on this site hides the owl and blocks new captures and page-understanding requests. That user choice survives navigation and browser restarts and can be reversed in the popup.

YouTube/youtu.be, Netflix, Prime Video, Disney+, Hotstar, Hulu, Twitch, Spotify, TikTok, Instagram, Facebook, X/Twitter, Reddit, Snapchat, Pinterest, Vimeo, Dailymotion, Kick, SoundCloud and Discord are stronger permanent blocks. They cannot be allowed from the popup, content scripts do not initialize there, queued legacy items are removed, and the desktop refuses their URLs.

Useful memory, without selecting text

Remember: on an AI chat it saves the latest completed user/assistant turn. On another page it saves the title, URL and a sanitized visible-text snapshot. It is written to the browser queue first and synced to the desktop. Offline items remain until the app reconnects; a failed or full queue is reported.

Automatic: on ChatGPT, Claude and DeepSeek, a detected send immediately stages the user's prompt in the durable local queue. When the assistant reply completes it joins that same turn. If completion is not detected, the prompt becomes a prompt-only capture after 12 minutes. Existing and lazily loaded history are skipped. No model importance decision can silently discard the raw turn.

Page understanding: opening the owl only shows its controls. Choose Understand this page to send the URL, title, selection and at most 6,000 visible-text characters to the model configured in your desktop app. This does not save the page. No screenshots, video frames, password fields or form values are read.

Raw capture first, synthesis later

Automatic AI turns are saved as source evidence before extraction. The desktop model may later convert useful facts into the four memory quadrants, but a model classification is never allowed to erase the raw browser turn.

This separates reliable transport from probabilistic interpretation: retries and exact event keys protect delivery, while generated summaries remain reviewable through their raw capture citations.

Troubleshooting

  • Browser not paired / pairing needs renewal: copy the current secret from desktop Settings and pair this browser. Pairing automatically sends its ready captures.
  • Desktop offline: open OwlThread. Ready captures retry automatically; opening the popup or pressing Reconnect also resumes delivery. Chrome can suspend background workers, so the persistent retry alarm may take up to a minute.
  • Connected, but no memory visible: check the capture project shown below the queue counts. In Connection settings, Use desktop project applies the app's selected project to future captures. Delivered raw captures appear in the app before extraction; the four memory categories are created separately by extraction. A staged prompt waits for its AI reply or becomes prompt-only after 12 minutes.
  • Owl missing: check the current site's choice, global visibility, and browser site access. Permanently blocked sites intentionally have no owl.
  • Changed the extension: reload it on your browser's extensions page, then refresh the website.
  • Browser page: settings, new tabs, extension stores and some built-in viewers block injected controls. Open a regular website.
  • AI response missed: live layouts can change. A response begun before installation, an unrecognized send action, switching chats during generation, or an oversized reply can be missed. Press Remember current turn/page; no selection is required.

The shortcut is Ctrl+Shift+O; change it on the browser's extension shortcuts page if it conflicts.
